# Gorzo Product Documentation

Welcome to the official documentation repository for **Gorzo**, a digital platform that empowers informal grocery vendors in Kenya, known as **Mama Mboga**, to connect with tech-savvy youth customers through a Progressive Web App and a native mobile app.


## Project Overview

Gorzo is designed to bridge the gap between traditional informal grocery vendors and modern consumers by providing tools for:

- Inventory management  
- Order processing (individual and group buying)  
- Payment integration with M-Pesa  
- Performance tracking for vendors  
- Convenient browsing and ordering for customers  

The platform aims to increase vendor sales, reduce grocery spoilage, and support local economic participation within Kenyan communities.
